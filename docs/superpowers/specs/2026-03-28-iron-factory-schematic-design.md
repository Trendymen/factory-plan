# 铁矿垂直工厂交互式示意图 — 设计文档

## 概述

为幸福工厂(Satisfactory)前期（太空电梯前）设计一个铁矿全产线双层垂直工厂的交互式浏览器示意图。全线适配 Mk.1 传送带，预留 Mk.2 升级路径。

## 产线配比

| 机器 | 数量 | 输入/min | 输出/min | 功耗 |
|------|------|----------|----------|------|
| 冶炼炉 | 4 | 铁矿 30×4=120 | 铁锭 30×4=120 | 4MW×4=16 |
| 铁板制造机 | 2 | 铁锭 30×2=60 | 铁板 20×2=40 | 4MW×2=8 |
| 铁棒制造机 | 4 | 铁锭 15×4=60 | 铁棒 15×4=60 | 4MW×4=16 |
| 螺丝制造机 | 4 | 铁棒 10×4=40 | 螺丝 40×4=160 | 4MW×4=16 |
| 强化铁板组装机 | 1 | 铁板30 + 螺丝60 | 强化铁板 5 | 15MW |
| 转子组装机 | 1 | 铁棒20 + 螺丝100 | 转子 4 | 15MW |

- **总计:** 16 台机器，86 MW
- **产出:** 强化铁板 5/min + 转子 2.4~4/min + 铁板余量 10/min

## Mk.1 适配 + Mk.2 升级路径

全线使用 Mk.1 传送带 (60/min)。转子组装机螺丝入口需要 100/min，Mk.1 阶段限流至 60/min，转子以 60% 效率运行 (~2.4/min)。

**升级操作:** 解锁 Mk.2 带后，只需替换 3 段带：

| # | 位置 | Mk.1 效率 | Mk.2 效率 |
|---|------|-----------|-----------|
| ① | 螺丝#1+#2 合流出口 | 60/80=75% | 80/80=100% |
| ② | 螺丝#3+#4 合流出口 | 60/80=75% | 80/80=100% |
| ③ | 螺丝→转子组装机入口 | 60/100=60% | 100/100=100% |

所有机器、分流器、合流器、电线杆位置不变。

## 矿石输入

2 台 Mk.1 采矿机（正常节点），各出 60/min，走 2 条独立 Mk.1 带，不合流：
- 采矿机 A (60/min) → 分流 30+30 → 冶炼炉 #1, #2
- 采矿机 B (60/min) → 分流 30+30 → 冶炼炉 #3, #4

## 地基尺寸

**8×7 地基（每格 8m×8m），双层，共 112 格。**

### 1F 冶炼 + 基础加工层 (8×7)

|----|------|------|
| 1 | 1格 | 矿石输入 2 条 Mk.1 带 + 分流器 |

## 传送带详细路由

### 1F 路由

**铁板线 (冶炼炉 #1+#2 → 铁板制造机):**
- 冶炼 #1 (30锭/m) + 冶炼 #2 (30锭/m) → 合流器 → 60锭/m (Mk.1满载)
- → 分流器 → 30+30 → 铁板制造机 #1, #2
- 铁板 #1 (20板/m) + 铁板 #2 (20板/m) → 合流器 → 40板/m → 升降机↑2F

**铁棒线 (冶炼炉 #3+#4 → 铁棒制造机):**
- 冶炼 #3 (30锭/m) + 冶炼 #4 (30锭/m) → 合流器 → 60锭/m (Mk.1满载)
- → 分流器 60→30+30
  - 左30 → 分流器 30→15+15 → 铁棒制造机 #1, #2
  - 右30 → 分流器 30→15+15 → 铁棒制造机 #3, #4
- 铁棒 #1+#2 → 合流 30/m → 合流 #3+#4 (30/m) → 总合流 60棒/m → 升降机↑2F

### 2F 路由

**铁棒分流:**
- 升降机到达 60棒/m → 分流器 60→40+20
  - 40棒 → 螺丝线 (再分流 4×10)
  - 20棒 → 直通转子组装机

**螺丝线:**
- 40棒 → 分流 20+20 → 各再分流 10+10 → 4 台螺丝制造机各 10棒→40螺丝/m
- 螺丝 #1+#2 → 合流 80/m [⚠️Mk.1限60] → 分流 60+20
  - 60螺丝 → 强化铁板组装机 (Mk.1满载)
  - 20螺丝 → 汇入右侧
- 螺丝 #3+#4 → 合流 80/m [⚠️Mk.1限60]
- 右侧 80 + 左余 20 → 合流 100/m [⚠️Mk.1限60] → 转子组装机

**铁板分流:**
- 升降机到达 40板/m → 分流 30+10
  - 30板 → 强化铁板组装机
  - 10板 → 储存箱📦1

## 交互功能

### 楼层切换 Tab
- 1F / 2F / 剖面 三个标签页
- 切换时平滑过渡，当前层全彩，非当前层灰显

### Toggle 显示/隐藏
- ⚡ 电力线 (金色虚线)
- 🔧 传送带 (材料色彩编码)
- 📦 储存箱
- 🔶 Mk.2 升级标记 (橙色高亮)

### Hover 悬停高亮
- 鼠标悬停机器 → 高亮该机器 + 关联传送带路径
- Tooltip 显示: 名称·配方·输入/输出速率·当前效率%

### Click 详情弹窗
- 点击机器 → 弹出详情浮层
- 内容: 完整配方·输入来源·输出去向·功耗·所连电线杆编号·Mk.2升级后变化

### 传送带动画
- CSS stroke-dashoffset 动画，虚线流动表示方向
- 颜色区分材料: 矿石(棕)·铁锭(橙)·铁板(青)·铁棒(蓝)·螺丝(绿)·组装产物(紫)
- Mk.2 升级段用橙色虚线标记

### 剖面视图
- Tab 页面或侧边面板
- 展示 1F↔2F 垂直关系: 升降机位置·电线杆跨层连接

### 产能面板 (静态)
- 右侧固定面板: 各材料吞吐量·效率条
- 总功耗 86MW
- 转子行标注 "60% → 升级Mk.2后100%"

## 技术实现

- **单 HTML 文件**，纯 SVG + CSS + JavaScript，无外部依赖
- 浏览器直接打开即可使用
- **页面结构:**
  - 顶栏: 楼层 Tab + Toggle 开关 + 图例
  - 主区域 (~70%): SVG 俯视平面图
  - 侧栏 (~30%): 剖面视图 + 产能面板
  - 弹窗: 点击机器后绝对定位浮层
- **传送带动画:** CSS `stroke-dasharray` + `animation: stroke-dashoffset`
- **Hover/Click:** JS 事件委托
