## 1. 一句话定位

**1× 参考工厂 = 37 个最终产物（mainNode）各按「单台机器 @100%」对外交付**，零过量外运。物理机台一次按 **T9 满载**建好，按 **T6 → T7 → T8 → T9** 分阶段点亮（翻 Power Switch + 插碎片 + 调超频），**最终目标 = T9**。

核心约束：

- 每个 mainNode 的**对外交付量 = 该配方单台机器 @100% 的产量**（零过量）。
- 机器可超频（**≤250%**，1–3 个动力碎片）来配平**内部消耗**——内部消耗使中间品总产量远高于其 1×100% 外运量。
- 升 Tier ≠ 加机器，而是给已建好的物理机台**逐阶段调超频**。

## 2. 关键设计选择：F金锭走铝配方

F金锭 在转化站有 **铁 / 铝 / 钦金** 三套配方。本设计选 **铝配方**：

```
120 铝锭 + 60 活性SAM物质 → 30 F金锭   （转化站，单台@100%）
```

**为什么选铝配方：**

| 配方 | 后果 | 是否可行 |
|------|------|---------|
| **铝配方（选用）** | 金属负载转嫁到新建铝链 C7，**现有 BP1-15 物理机台一台不补**即可满足 T9 | ✅ 最省 |
| 铁配方 | 铁锭需求飙到 **1878/min**，18 台喂不饱，需 **26 台** | ❌ 大改 |
| 钦金配方 | 击穿钦金锭，需 **11 台** | ❌ 击穿 |

一句话：**铝配方让「现有产线一台不补」成立**，代价只是多建一条铝链（反正 C7 本来就要为铝制外壳/复合铝板等新产物而建）。

## 6. 关键修正说明（相对旧总文档）

重算中改了三处旧数字，列明原因，方便对照老文档。

### 修正 1 · 二氧化硅旧值漏算副产

- **旧写**：uplift 689.58/min
- **真实净需**：589.58/min（铝 Ficsite 路线）/ 506.25（不含铝 Ficsite 额外铝锭）
- **原因**：旧值**漏算了氧化铝溶液的副产二氧化硅**（每台 50/min，C7 抵掉约 276/min）。
- **结论**：**7 台物理足够**（T9 7 @225%），无需扩建。

### 修正 2 · 活性SAM物质旧值与时间线矛盾

- **旧写**：uplift 200/min（与「BP11 永 2 台」矛盾）
- **真实净需**：140/min（铝 Ficsite 路线）
- **结论**：**2 台 @233% 正好够**，时间线矛盾消解。

### 修正 3 · T6 两处超频喂不饱

- **T6 铁锭**：旧 226% → 修正 **237%**（旧值喂不饱 T6 的 640.5/min 需求）。
- **T6 螺丝**：旧 241% → 修正 **249%**（旧值喂不饱 896/min 需求）。
