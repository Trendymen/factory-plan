# BP-BUS-FILLER 总线填充段

## 概要

- **集群**: 集群间空隙（按需，0-2 个）
- **规格**: Mk2 单实例（可复制贴贴）
- **建筑**: **0 台机器**（仅 belt + 墙体锚点）
- **作用**: 当集群之间有意留走道、扩容预留、或地形障碍时填充，保持总线连续

> 本蓝图无生产机器；所有 belt T6 一次建造到位，不涉及 Power Switch / Power Shard。T7+ 升 Tier 时本蓝图无任何操作。

## 极简示意图

```floorstack
# BP-BUS-FILLER 原料中继段
1F (0-12m) | （空，仅地坪，无机器） |  |  |
2F (12-24m) | （空，仅地坪，无机器） |  |  |
3F (24-35m) | （空，仅地坪，无机器） |  |  |
屋顶 (35-40m) | 6条 Mk5 原料带路过本层，不取料 |  |  |
```

> 无生产机器，仅原料带中继/填充用；当集群间需要走道或扩容预留时插入，原料带穿屋顶连续通过，本层不消耗任何物料。
