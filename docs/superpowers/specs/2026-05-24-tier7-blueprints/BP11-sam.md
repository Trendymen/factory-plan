# BP11 活性SAM物质 + SAM物质波动器 (C5 末)

## 概要

- **集群**: C5 末端（紧贴 BP10b 之后；C5 最后一个蓝图）
- **规格**: Mk2 单实例
- **机器**: **3 台一次物理建造到位**（2 reanimated-sam 构筑站 + 1 sam-fluctuator 制造站）
- **激活时间线**: T6 = T7 = T8 = T9 = **3 台全通电**（uplift 1.0x — 整厂唯一 T6 就满载的蓝图）
- **产能 T6**: 活性SAM物质 90/min · SAM物质波动器 10/min

> **核心设计原则**：3 台 T6 已全部物理建造且全部通电；T7-T9 不增加机器、不变 shard、不需要 Power Switch 分网（属于 BP01 统一模式的退化情形：所有机器一次到位 + 全部通电）。

## 极简示意图

```floorstack
# BP11 活性SAM物质 + SAM物质波动器 (C5 末) · Mk2 · 自下而上
1F (0-12m) | 制造站×1（SAM物质波动器） | 活性SAM物质 60·电线 50·钢管 30 | SAM物质波动器 10/min → 上屋顶 | ↑屋顶:SAM物质波动器

屋顶 (35-40m) | 取电线/钢管喂 1F / 产物外运 | 电线 50·钢管 30（外部来料） | 活性SAM物质 30·SAM物质波动器 10 → 外运 |
```

> 全厂唯一 T6 即满载蓝图（无 Power Switch 分网）；2F 构筑站产 90/min 活性SAM物质，60 下送 1F 制造站、30 上屋顶外运；电线+钢管从屋顶下行喂 1F 制造站；SAM物质波动器上行至屋顶后外运。
